# 乙級室內配線 模擬配電盤（第二站）

網頁版「模擬練習」配電盤：面對器具板 / 操作面板拉線，通電測試功能，依評審表自動評審。
目前題目（選單 ☰ 切換，或網址加 `?q=q2-2`；各題進度分開保存）：
- **第二站第一題**：電動機正反轉兼 Y-Δ 啟動控制電路（老師 18 步）。
- **第二站第二題**：電動機正反轉兼 Y-Δ 啟動附瞬時停電保護控制電路。新增器具：KR 保持電驛（SC 設定／RC 復歸，停電仍記住方向）、TR2／TR3 斷電延遲計時器（5 秒／10 秒）、EMS 緊急停止（蕈狀、按一下自鎖）。參考接線 28 步、13 條過門線依電路圖編排；功能劇本含瞬停 5 秒內自動依原方向再起動、長停電不再起動、OFF 停機（TR3 鎖 10 秒）不被誤判為停電、EMS、過載。通電測試有「模擬瞬停 1 秒」按鈕。
  - ※ KR（11 腳）與斷電延遲計時器（8 腳）的**腳位是常見配置的假設**，考場實物不同時只改 `src/library/keepRelay.ts`、`timer.ts`。

主電路視為已配妥，考生配控制線路。

## 執行

```bash
npm install
npm run dev      # http://localhost:5178
npm test         # Vitest：引擎與劇本測試
npm run build    # 產出 dist/index.html：單一檔案（JS/CSS/圖片全內嵌），直接雙擊即可開啟，不需伺服器
```

## 玩法

- **自由配線**：滑鼠移到器具展開端子（真實端子編號：MC a左/a右/b左/b右 + IEC 13-14/43-44/21-22/31-32，TR 8-pin）。點端子開始拉線，再點另一端子完成。TB3/TB4 為雙排端子台，靠門那顆螺絲是已配妥的過門線（灰色虛線），考生點另一顆；接到 TB3.n（或 TB4.n）之後會自動從另一塊板的 TB4.n（TB3.n）接續拉線，一顆光點沿過門線滑過去提示位置（不縮放，目標在畫面外才平移），Esc 可取消；NFB、D-F 端子可直接點。每端子最多 2 條線。
- **步驟引導**：依老師 18 步驟（`題目/老師接線步驟.jpg`）逐條提示，接錯會拒絕，完成一步自動前進並轉身到下一條線所在面板。
- **通電測試**：點器具板上的 NFB 把手投入電源、按住操作面板的 FWD/REV/OFF 按鈕（整顆按鈕都是按壓區，帽子會真的按下去；通電測試時器具不放大）、調 TR 秒數；TH-RY 右側是和端子分開的操作區：紅色「過載」鈕模擬跳脫（指示窗變紅、本體閃紅框）、藍色「復歸」鈕復歸，右鍵器具也有同樣項目。燈會亮並發光、BZ 鳴叫時整顆震動並有聲波圈（音效可關）、帶電導線依電工法規相色上色（R 紅、S 白、T 黑）。NFB 投入／切離時把手會上下翻（像扳鍘刀），三極閃一下電弧。
- **動作解說**（通電分頁勾選）：每一波動作放慢（0.5 秒，慢動作 1.2 秒）並依序說明因果，例如「按下 FWD：a 閉合（→ MCF、KR）」→「MCF 線圈得電 → 動作：a左 閉合（自保）、b左 打開（互鎖 MCR）…」→「TR1 得電，開始計時 5 秒」、「R2 亮（Y 啟動中）」。板上對應的端子亮一圈（閉合綠、打開橘、得電黃）、器具外框發光、剛帶電的導線閃一下，畫布下方有字幕，單線圖開著會同步標示。接點用途（自保、互鎖、供電給誰）由實際接線推導，等效接法也標得對。計時器與瞬停用模擬時間，不會因為放慢而失真；時間軸可點選重播。事件由模擬器 trace 產生（`src/engine/trace.ts`），有 vitest 驗證因果順序。
- **器具設定視窗**（SimuCir 風）：雙擊器具、右鍵「⚙ 設定…」或資訊卡的「⚙ 設定」開啟。可改標籤、用途說明、TR／TRF 的計時秒數（或跟隨通電分頁滑桿）、按鈕／燈的顏色、按鈕是否自鎖（EMS）；右側是腳位示意與每個端子目前的接線去向。設定依題目存在瀏覽器，匯出／匯入 JSON 會一併帶出；「回復預設」還原題目原值。只動外觀與動作參數，不動腳位與接線。
- **場景動畫**（通電分頁最上面，⧉ 可浮成可拖曳／改大小的視窗）：三相電動機側視圖依接觸器吸合狀態動作——MCF／MCR 決定正轉（順時針）／反轉（逆時針），MCS 吸合為 Y 啟動（爬到六成轉速）、MCD 為 Δ 運轉（全速），斷電後慣性滑行停下；旁邊的繞組圖標出 U V W 各接哪一相（反轉時 R、T 對調）與 X Y Z 目前是 Y 接（短接成中性點）還是 Δ 接；MCF＋MCR 或 MCS＋MCD 同時吸合、TH-RY 跳脫、EMS 會顯示警示；下方狀態清單含 TR 倒數。主電路在模擬器裡視為已配妥，所以狀態由接觸器推得；題目可用 `scene` 欄位指定器具 id，預設依 MCF／MCR／MCS／MCD、TR｜TR1 猜。
- **評審**：結構檢查（器具未使用、接到 TB1 電源側、端子超過 2 線、過門線單邊）＋ 4 條功能劇本（正轉、反轉、互鎖、過載）＋ 與參考接線的差異提示（電氣等效比對，a左/a右、TB 腳位互換不算錯）。
- 器具板與操作面板畫在**同一張畫布**上，拉線時直接平移過去；工具列的「全景／器具板／操作面板」或 0 / 1 / 2、Q / E 是把鏡頭轉到那塊板子，引導模式會自動轉到下一條線所在的板子。滑鼠移到器具上，器具會**原地放大**（畫面越小放得越大，已經夠大就不放大），端子好點；點器具會把它放得更大並固定（浮在導線上方、描黃邊）；在它上面選了端子後，滑鼠移出器具就自動還原，接著去點下一個端子。再點一次器具、點空白或 Esc 也會解除。端子上方有別的導線經過時，點擊仍以端子優先。右側面板可用邊緣的 ⟩ 縮成窄帶（只留模式、導線數、計時、下一條線），讓畫布更大。滾輪縮放、拖曳平移、F 全景、Delete 刪線、Esc 取消。**滑鼠右鍵**會依按到的東西開選單：端子（開始／完成拉線、刪除該端子上的線、釘選說明）、導線（選取、定位另一端、刪除）、器具（釘選說明、一次刪除該器具全部導線）、空白處（復原、全景）。進度自動存在瀏覽器（localStorage），可匯出 / 匯入 JSON。
- 器具板左上依講義外觀：電源由上方以紅白黑三線引入 TB1，再引到 NFB 電源側（考場已配妥，僅顯示）；NFB 為三極並排、共用把手，負載側 R S T 供控制電路取用（內部端子 id 仍是 A/B/C）。
- **單線圖**：配電盤上按**滑鼠中鍵**（或 D 鍵、右鍵選單）就在游標旁叫出，並把圖稍微放大聚焦到游標下的端子（它所在的那段線）或器具；再按一次中鍵（面板或圖上皆可）、D 或 Esc 收起。工具列「單線圖」按鈕也可開關。浮動視窗可拖曳、拉邊改大小、滾輪縮放、拖曳平移、◐ 半透明。圖是依官方控制電路圖**重繪**的向量圖（R/T 相、器具與接點名稱都用本模擬器的），每個接點符號綁定實際端子（例如 MCF 自保 = MCF.a左上/a左下）：
  - 滑到圖上的接點 → 面板上該器具閃紅框，**這個接點要接的端子**加紅色脈動圈（按鈕／燈指到引接小 TB）；點符號鏡頭帶過去。
  - 滑到面板上的端子 → 圖上**它所在的那一段線（節點）**亮黃；滑到器具 → 圖上它的符號亮框。
  - 步驟引導 → 下一條線在圖上對應的那一段紅色脈動，兩端接點標紅，底部顯示步驟說明。
  - 左半主電路（考場已配妥）同樣是綁實體主端子的符號（接觸器 R-U／S-V／T-W、TH-RY 加熱器、NFB 各極、TB1／TB2、電動機 U V W X Y Z），滑過一樣會指到面板上的主端子。
  - 視窗：− ／百分比（點一下回整張）／＋、滾輪以游標為中心縮放、雙擊放大 2 倍（已很大時回整張）、拖曳平移（不會把圖拖出視窗）、改視窗大小時自動跟著縮放；背景預設接近白紙，◐ 切換成霧化玻璃（透出後面的配電盤）。
  - 驗證：`src/model/schematic.test.ts` 以圖面幾何算出連通性（端點落在線上才算接，交叉不算），逐對比對老師參考接線的節點，並檢查每個符號對到器具庫真的元件、參考接線用到的元件都畫且只畫一次；主電路則做功能驗證：只看圖面，算出各接觸器閉合時電動機各端帶哪一相——正轉 Y（U V W = R S T、X Y Z 短接成中性點）、正轉 Δ（X=V、Y=W、Z=U 的相）、反轉 Y／Δ（R、T 對調）、MCF+MCR 或 MCS+MCD 同時閉合會短路、TH-RY 三個加熱器各串在一相上。另有故意畫錯的測試確認驗證器抓得到。資料在 `q2-1.schematic.ts`。
- 操作面板以**開門後的背面**呈現（水平鏡射），與實際配線方向一致。
- 依考場實務（講義實物布局圖），操作面板的燈／按鈕已由考場引接到旁邊**無編號的雙排小端子台**：上排螺絲壓考場的引接線（灰色虛線，僅顯示），下排留給考生接到 TB4。燈／BZ 用 3P（中間那格未引接，不顯示），按鈕用 4P；操作面板是鏡射的開門背面，畫出來由左到右正好是講義上的 a a b b。器具板的 TH-RY 輔助接點 95/96/98（c b a）同樣以一條引接線接到本體下方的 3P 小 TB，小 TB 的端子點依引接來源上色（c 紫、b 橘、a 藍）。器具板底部的 TB2 為上下兩排 8P，下排引出 U V W X Y Z 六條線到電動機（Y-Δ），第 8 格 G 以綠黃線接電動機與接地端子板 G（僅顯示）。
- **設備接地**（題目說明二）：考生要從控制箱的接地線端子板 G 接一條 8mm² 綠線到檢定崗位的接地極端子板 E（畫在器具板下緣外、箱外）。接地端子只能與接地端子相接，接上後導線自動變成粗綠線、不走線槽；沒接列為重大缺點。參考接線與步驟引導的最後一步就是這條。滑鼠停在小 TB 端子上會顯示它引接自哪個接點（等同三用電表量通路）。引接順序定義在 `q2-1.ts` 的 `preWired`。

## 結構

```
src/library/                器具庫：每種器具一個檔案（mc.ts、timer.ts、thry.ts、operator.ts、power.ts、terminalBlocks.ts）
                            index.ts 為註冊表 LIBRARY 與 place() 放置函式；選單「器具庫」可瀏覽所有器具腳位
src/model/questions/q2-1.ts 題目：用 place(kind, id, panel, x, y) 把器具放到圖紙、線槽、過門線、老師 18 步（chain 字串）、功能劇本
src/engine/simulator.ts     逐 tick 電驛邏輯模擬（union-find 導通、相別判定、TR 計時、短路）
src/engine/grader.ts        結構檢查 + 劇本 + WL 節點雜湊差異提示
src/view/panel.ts           SVG 面板：端子層、導線走線槽、pan/zoom、模擬顯示；器具外觀交給 art/
src/view/art/               器具「照片級」外觀：defs.ts（共用漸層／濾鏡）、parts.ts（箱型端子、螺絲、旋鈕、LED）、
                            每種器具一檔（mc.ts、timer.ts、keepRelay.ts、thry.ts、nfb.ts、fuse.ts、operator.ts、terminalBlocks.ts），index.ts 註冊表
src/view/deviceDialog.ts    器具設定視窗；覆寫值存在 store.ts 的 overrides
src/view/scene.ts           場景動畫（電動機轉向／Y-Δ／繞組圖／狀態清單）；floatWin.ts 浮動視窗
src/view/hud.ts             右側控制列；src/view/report.ts 評審報告
```

畫面配色採 SimuCir-Web 風：深色工具列與右側面板、淺灰沖孔板畫布、象牙白盤面。器具外觀以 OMRON 實物為本（J7KN、P2CF-08＋H3CR、A22），光源統一左上，殼體與零件不描邊、只靠漸層色塊與細亮暗線區分；可接線端子的螺絲由端子層畫（金屬漸層），各器具只畫底下的端子口袋與壓線框。
